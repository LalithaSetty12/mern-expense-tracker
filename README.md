# 💰 MERN Stack Expense Tracker

A web application built using the MERN stack to help users manage their expenses, set monthly budgets, and monitor their spending by category.

## ✨ Features

- User registration and login
- Expense management
- Monthly budget creation by category
- Expense categorization
- Budget spending and remaining-balance display
- Recurring expense option
- Dashboard for managing budgets and expenses

## 🛠️ Technologies Used

**Frontend**
- React
- Vite
- JavaScript
- HTML
- CSS

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/LalithaSetty12/mern-expense-tracker.git
cd mern-expense-tracker
```

### 2. Set up the backend

```bash
cd backend
npm install
```

Create a `.env` file in the backend folder and configure the environment variables required by your application, including your MongoDB connection string and any authentication secret required by your code.

Start the backend using the script configured in `backend/package.json`.

### 3. Set up the frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL shown in the terminal to access the application.
